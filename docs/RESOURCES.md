# Игровые ресурсы

Лист персонажа → «Способности» → «Игровые ресурсы». Мастер настраивает до 50 независимых счётчиков: ячейки заклинаний круга 1–9 или расходуемые способности. Для каждого задаются название, максимум (1–999), текущий остаток и количество, возвращаемое за короткий и долгий отдых. Восстановление прибавляется к остатку, но не превышает максимум. Ноль означает отсутствие автоматического восстановления при этом отдыхе. Для полного восстановления задайте количество равным максимуму.

Лимиты задаёт мастер: приложение не определяет их по классу, уровню, мультиклассу или тексту способности. Можно создать несколько независимых пулов одного круга с разными названиями и восстановлением. Заговоры не используют счётчик ячеек. Ресурс не связан автоматически с выданной карточкой: расход отмечается отдельной кнопкой «Потратить 1», ошибку можно исправить через «Вернуть 1» или историю.

Игрок видит остатки и настройки, но не может менять их. Сервер проверяет права, версию персонажа, границы и повтор операции. Настройка, расход, возврат и отдых записываются в историю; отменяется последнее совместимое изменение персонажа.

Перед отдыхом отображается список ожидаемых изменений. Мастер сам подтверждает выполнение условий отдыха. Кнопка изменяет только настроенные ресурсы: не здоровье, кости хитов, предметные заряды, эффекты или состояния. Долгий отдых использует только поле «за долгий отдых», не складывая его с коротким. Повторный отдельный отдых считается новым отдыхом и снова прибавляет заданное количество. Если восстанавливать нечего, запись в историю не создаётся.

Старые персонажи получают пустой список без пересчёта игровых значений. Ресурсы хранятся внутри JSON персонажа в SQLite, входят в резервную копию и историю; новая миграция таблиц не требуется. Импорт библиотеки переносит шаблоны карточек, а не ресурсы персонажей. Несохранённая настройка защищена предупреждением об уходе. При конфликте форма остаётся открытой, но для сохранения необходимо согласовать изменения и открыть актуальную версию заново.
